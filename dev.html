Over Henk's File Transfer

Wat is het?

Henk's File Transfer is een directe peer-to-peer (P2P) applicatie om bestanden uit te wisselen. Bestanden worden rechtstreeks van jouw browser naar de browser van de ontvanger gestuurd en worden niet door deze applicatie op een server opgeslagen. De verbinding loopt via WebRTC; voor het opzetten van de verbinding wordt PeerJS-signaling gebruikt.

Nieuw in v1.2.01.21

Verbeterde foutafhandeling, controle op lege en te grote bestanden, betere bestandsnaamlogica, dubbele-bestandencheck en duidelijkere P2P-uitleg.

Belangrijk

De verzender moet dit venster open houden totdat de ontvanger klaar is. Grote bestanden gebruiken veel browsergeheugen. Daarom is de standaardlimiet ingesteld op 1 GB totaal.

    Over Henk's File Transfer

    Wat is het?

    Henk's File Transfer is een veilige, directe peer-to-peer (P2P) applicatie om bestanden uit te wisselen. Bestanden worden rechtstreeks van jouw apparaat naar de ontvanger gestuurd zonder dat ze op een externe server worden opgeslagen.

    Wat doet het?

    Het pakt geselecteerde bestanden automatisch in als een ZIP-archief (bij meerdere bestanden) en zet een beveiligde verbinding op zodat de ontvanger het bestand direct kan downloaden.

    Hoe moet je het gebruiken?

      Selecteer sleep je bestanden in het vak of klik om ze te kiezen. Genereer Klik op 'Start Zippen & Genereer Deellink'. Deel Stuur de gegenereerde unieke link naar de ontvanger.
    1. Omdat de overdracht rechtstreeks via jouw browser loopt, stopt de download als je het tabblad sluit voordat de ontvanger klaar is.
